Linux Commands Used

#!/bin/bash Specifies Bash shell interpreter.

">>" (Append) = Allows text to be added to existing variable 

"cat" (Catenate) = Shows the poem file contents within the terminal.

"cd" (change directory) = Navigated to the appropriate directory.

"chmod +x" (change mode) = Allows bash script to be become executable.

"echo" = Printed text and placed the poem lines into the file.

"ls" (list) = Shows directory contents.

"mkdir -p" (make directory)= Creates the poetry directory if it does not exist.

"mv" (move)= Rename/change the file type from .txt to .sh.

"pwd" (print working directory) = Shows the current working directory.

"touch" = Creates the poem text file.

"whoami" = Print the username of current user
